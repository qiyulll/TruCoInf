  4. 下载模型到数据盘

  python << 'EOF'

  5. 创建配置文件

  THRESHOLD_API_SERVER: 0.8

  CONFIG_API_SERVER:
    - weight: '/root/autodl-tmp/weights/qwen/Qwen1.5-7B-Chat'

        0: '12GiB'

      name: 'Qwen1.5-1.8B-Chat'

  几个注意点：

  - PyTorch 版本：你的镜像是 2.8.0 + CUDA 12.8，比项目要求的 2.2.1
  新很多。大概率兼容，但如果遇到奇怪的报错，可能需要降到 2.2.1
  - 磁盘占用估算：模型约 18GB，conda 环境约 5-8GB，代码+编译产物约 1GB，总共约 25-30GB，50GB

  - 如果数据盘不够，可以只下 1.8B 模型先跑通单模型，再考虑 7B

整体方案

  文件结构
  
  config.yaml                  # 通用协同推理配置

  utils/eval_judge.py           # 评判工具（规则提取 + 小模型兜底）
  benchmark_accuracy.py         # 主评测脚本

  ---
  一、下载模型

  在 AutoDL 机器上，推荐用 modelscope（国内快）或 huggingface-cli：

  方法 1：ModelScope（推荐，国内不用翻墙）

  pip install modelscope

  # 下载 DeepSeek-R1-7B
  python -c "
  from modelscope import snapshot_download
  snapshot_download('deepseek-ai/DeepSeek-R1-Distill-Qwen-7B', cache_dir='/root/autodl-tmp/models')
  "

  # 下载 DeepSeek-R1-14B
  python -c "
  from modelscope import snapshot_download
  snapshot_download('deepseek-ai/DeepSeek-R1-Distill-Qwen-14B', cache_dir='/root/autodl-tmp/models')
  "

  方法 2：HuggingFace CLI

  pip install huggingface_hub

  huggingface-cli download deepseek-ai/DeepSeek-R1-Distill-Qwen-7B --local-dir /root/autodl-tmp/models/DeepSeek-R1-Distill-Qwen-7B
  huggingface-cli download deepseek-ai/DeepSeek-R1-Distill-Qwen-14B --local-dir /root/autodl-tmp/models/DeepSeek-R1-Distill-Qwen-14B       

  ---
  二、修改配置文件

  把模型路径改成实际下载位置：

  eval_configs/deepseek_7b.yaml 第 3 行：
  MODEL_PATH: '/root/autodl-tmp/models/deepseek-ai/DeepSeek-R1-Distill-Qwen-7B'

  eval_configs/deepseek_14b.yaml 第 3 行：
  MODEL_PATH: '/root/autodl-tmp/models/deepseek-ai/DeepSeek-R1-Distill-Qwen-14B'

  （具体路径取决于 modelscope 下载后的目录结构，下载完 ls 看一下）

  四、跑评测

  数据集（MMLU、GSM8K、RAGBench）会自动从 HuggingFace 下载，不需要手动准备。

  cd ~/autodl-tmp/zkhook-gac

  # 跑 DeepSeek-R1-7B（约 20G 显存）
  python benchmark_accuracy.py --config eval_configs/deepseek_7b.yaml --dataset mmlu gsm8k ragbench

  # 跑 DeepSeek-R1-14B（约 30G 显存）
  python benchmark_accuracy.py --config eval_configs/deepseek_14b.yaml --dataset mmlu gsm8k ragbench

  # 如果想先少量测试（比如每个数据集 100 条）
  python benchmark_accuracy.py --config eval_configs/deepseek_7b.yaml --dataset mmlu --num-samples 100

  # 跑完后汇总对比
  python benchmark_accuracy.py --summarize results/
