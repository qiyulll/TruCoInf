下层：zkhook 零知识证明：这是 P/V 交互的核心。
P (Prover) 和 V (Verifier) 的完整交互

                      ┌─────────────────────────────────┐
                      │         推理阶段 (在线)           │
                      └─────────────────────────────────┘

                                                │
                                      ZK Hooks (Layer 0 only)
                                                │
                                     ┌──────────┴──────────┐
                                     ▼                     ▼
                              Attention 证据            FFN 证据
                              ┌────────────┐       ┌────────────┐
                              │ input X    │       │ input X    │
                              │ Q,K,V 输出  │       │ up 输出    │
                              │ O 输出      │       │ gate 输出  │
                              │ 权重 W      │       │ down 输出  │
                              │ 量化 int32  │       │ 权重 W     │
                              └─────┬──────┘       └─────┬──────┘
                                    │                    │

                      ┌─────────────────────────────────┐
                      │       证明阶段 (P 执行)           │
                      └─────────────────────────────────┘

    P 拥有:
      - 输入 X (用户 prompt 的隐藏状态)
      - 权重 W (Q/K/V/O/up/gate/down 7 个权重矩阵)
      - 输出 Y (各层计算结果)
      - 查找表 (Softmax/SwiGLU 的预计算表)
      - Nonce (request_id，防重放)

    transformer_prove 执行流程:
      ┌──────────────────────────────────────────────────┐
      │  1. 量化: float32 → int32 (scale = 2^12)         │
      │  2. 对 X, W, Y 生成多项式承诺 (BLS12-381 曲线)    │
      │  3. 证明 Attention: X·Wq=Q, X·Wk=K, X·Wv=V      │
      │     Softmax(QK^T/√d)·V → attn_out               │
      │     attn_out·Wo = O                              │
      │  4. 证明 FFN: X·Wup=up, X·Wgate=gate             │
      │     SwiGLU(gate)⊙up → hidden                     │
      │     hidden·Wdown = ffn_out                       │
      │  5. 证明 Skip Connection: out = input + sublayer  │
      │  6. 将 nonce 绑定到 transcript (SHA256)            │
      │  7. 输出: proof.bin (承诺 + 证明数据)              │
      └──────────────────────────────────────────────────┘


                      ┌─────────────────────────────────┐
                      │       验证阶段 (V 执行)           │
                      └─────────────────────────────────┘

    V 拥有:
      - proof.bin (P 生成的证明文件)
      - tables.bin (公共查找表，Softmax/SwiGLU)

    V 不知道:
      - ❌ 输入 X (用户说了什么)
      - ❌ 权重 W (模型参数是什么)
      - ❌ 输出 Y (模型回答了什么)

    transformer_verify 执行流程:
      ┌──────────────────────────────────────────────────┐
      │  1. 读取 proof.bin 中的承诺和证明                  │
      │  2. 验证多项式承诺的正确性 (椭圆曲线配对)           │
      │  3. 验证矩阵乘法关系: Commit(X)·Commit(W)=Commit(Y)│
      │  4. 验证非线性操作 (tlookup 查找表证明)             │
      │  5. 验证 nonce 绑定 (防重放)                       │
      │  6. 输出: ✅ 验证通过 / ❌ 验证失败                 │
      └──────────────────────────────────────────────────┘
P/V 交互的关键设计

          Prover (P)                              Verifier (V)
          ─────────                               ──────────
          持有: X, W, Y, nonce                    持有: proof.bin, tables.bin

     1.   Commit(X) ──────────────────────────▶   收到 X 的承诺
          Commit(W) ──────────────────────────▶   收到 W 的承诺
          Commit(Y) ──────────────────────────▶   收到 Y 的承诺

     2.                 ◀── 随机挑战 r ──────────  V 发送随机数 (Fiat-Shamir: 用 SHA256
                                                   从 transcript 派生，非交互式)

     3.   计算证明 π:
          - 在 r 处打开多项式
          - 证明 Y = X·W (矩阵乘)
          - 证明非线性操作正确
          π ──────────────────────────────────▶   收到证明 π

     4.                                           验证:
                                                  - 承诺一致性 (椭圆曲线配对)
                                                  - 计算正确性
                                                  - nonce 新鲜性
                                                  → ✅ / ❌
实际实现是非交互式的（Fiat-Shamir 变换）：P 用 SHA256 哈希 transcript 来模拟 V 的随机挑战，所以整个过程是 P   
生成 proof → V 离线验证，不需要实时通信。
密码学原语：
  ├────────────┼────────────────────────────────────────────────┤
  │    组件    │                      用途                      │
  ├────────────┼────────────────────────────────────────────────┤
  ├────────────┼────────────────────────────────────────────────┤
  │ BLS12-381  │ 椭圆曲线，用于多项式承诺 (Pedersen commitment) │
  ├────────────┼────────────────────────────────────────────────┤
  │ Fr-tensor  │ 有限域上的张量运算 (模型计算映射到有限域)      │
  ├────────────┼────────────────────────────────────────────────┤
  │ G1-tensor  │ 椭圆曲线群上的张量运算 (承诺计算)              │
  ├────────────┼────────────────────────────────────────────────┤
  │ tlookup    │ 查找表证明，处理 Softmax/SwiGLU 等非线性操作   │
  ├────────────┼────────────────────────────────────────────────┤
  │ SHA256     │ Fiat-Shamir transcript 哈希                    │
  ├────────────┼────────────────────────────────────────────────┤
  │ polynomial │ 多项式承诺和求值证明                           │
  └────────────┴────────────────────────────────────────────────┘
P 在推理时通过 hook 截获 Layer 0 的所有中间值，对 X/W/Y 生成密码学承诺，然后证明"承诺背后的值确实满足Transformer 的计算关系"。
V 只看到承诺和证明，验证计算正确性，但完全不知道输入、权重和输出的具体内容。nonce机制保证每次推理的证明不可重放。

1. Attention 层（attn_prove/verify）
  - X · Wq = Q — 输入乘以 Q 权重矩阵
  - X · Wk = K — 输入乘以 K 权重矩阵
  - X · Wv = V — 输入乘以 V 权重矩阵
  - Softmax(QK^T / √d) · V — 注意力分数计算（Softmax 通过 tlookup 查找表证明）
  - attn_out · Wo = O — 输出投影

2. FFN 层（ffn_prove/verify）
  - X · Wup = up — up 投影
  - X · Wgate = gate — gate 投影
  - SiLU(gate) ⊙ up — SwiGLU 激活（SiLU 通过 tlookup 查找表证明）
  - hidden · Wdown = down — down 投影

3. Skip Connection + RMSNorm（rmsnorm_prove/verify；旧版 skip_connection.py 独立脚本已移除）-残差链接+
  - output = input + sublayer_output — 残差连接
  - RMSNorm(x) — 归一化


证明的是计算完整性（Computational Integrity），具体含义：
  ┌──────────┬───────────────────────────────────────────────────────────────────────────────────────────┐      
  │   保证   │                                           含义                                            │      
  ├──────────┼───────────────────────────────────────────────────────────────────────────────────────────┤      
  │ 计算正确 │ Layer 0 的矩阵乘法、Softmax、SwiGLU 确实按照 Transformer 的定义执行了，没有偷工减料或篡改 │      
  ├──────────┼───────────────────────────────────────────────────────────────────────────────────────────┤      
  │ 输入隐私 │ V 不知道用户输入了什么（X 被承诺隐藏）                                                    │      
  ├──────────┼───────────────────────────────────────────────────────────────────────────────────────────┤      
  │ 权重隐私 │ V 不知道模型参数是什么（W 被承诺隐藏）                                                    │      
  ├──────────┼───────────────────────────────────────────────────────────────────────────────────────────┤      
  │ 输出隐私 │ V 不知道模型输出了什么（Y 被承诺隐藏）                                                    │      
  ├──────────┼───────────────────────────────────────────────────────────────────────────────────────────┤      
  │ 防重放   │ nonce (request_id) 绑定到证明中，同一个证明不能用于伪造另一次推理                         │      
  └──────────┴───────────────────────────────────────────────────────────────────────────────────────────┘
